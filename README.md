# Smooth Train Analytics

> Десктопное приложение для визуализации графиков скорости, ускорения (с применением сглаживания), уклона, давления в тормозной магистрали и тормозном цилиндре поезда, режимов "Тяга" и "Торможение".

## О проекте

Приложение построено на `tkinter` и позволяет загружать данные из файлов, отображать несколько графиков в одном окне и применять сглаживание к сигналам скорости и ускорения.

**Отображаемые параметры:**
- Скорость движения
- Ускорение/замедление (сглаженное)
- Давление в тормозной магистрали
- Давление в тормозном цилиндре
- Давление в главном резервуаре (ГР..?)
- Уклон
- Режим "Тяга"
- Режим "Торможение"

---

## Стек технологий

| Компонент | Технология |
|-----------|------------|
| GUI | `tkinter` |
| Обработка данных | `pandas`, `numpy` |
| Визуализация | `matplotlib` (с интеграцией в `tkinter` через `FigureCanvasTkAgg`) |
| Работа с файлами | `os`, `sys`, `io` |

**Требования:**
- Python 3.13.14 (или выше)
- Библиотеки из `requirements.txt`

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/ваш-логин/smooth-train-analytics.git
cd smooth-train-analytics
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```
### 3. Запустить приложение

```bash
python train_speed_processor.py
```

## Планы по развитию

- Масштабирование графика
- Курсор
- Вывод всех параметров в выбранной точке графика
- Графики давления в ТЦ, ТМ, ГР на графике скорости
- График уклона на графике ускорения
- Сглаживание ускорения
- Графики режимов "Тяга" и "Торможение" на графиках скорости и ускорения
- Экспорт данных в Excel с выбранного участка графика
