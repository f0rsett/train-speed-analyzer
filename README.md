# Train Speed Analyzer

> Десктопное приложение для анализа параметров движения поезда по данным из Excel:
сглаживание сигналов, расчёт ускорений от сил тяги/уклона/сопротивления, определение
коэффициента K, интерактивные графики с зумом, выделением области и экспортом
статистики.

## Возможности

### Обработка данных
- **Загрузка Excel** (`.xlsx`, `.xls`) с автоматическим определением колонок времени и скорости.
- Переименование `Freal` → `Сила тяги` и перевод **кН → Н**.
- Поддержка трёх независимых ступеней сглаживания:
  - **① Скорость** — включена по умолчанию.
  - **② Ускорение — 1-е сглаживание**.
  - **③ Ускорение — 2-е сглаживание**.
- **5 алгоритмов сглаживания** для каждой ступени:
  - Стандартный (двойное сглаживание с коридором);
  - Экспоненциальное (EMA);
  - Фильтр Калмана;
  - Медианный фильтр;
  - Фильтр Савицкого–Голея.
 
### Физические расчёты
- **Скорость в м/с** из сглаженной скорости.
- **Ускорение** по конечной разности с шагом 10 точек.
- **Сила и ускорение от уклона** (масса поезда учитывается).
- **Ускорение от силы тяги** = `Freal / (M_поезда + M_инерц)`.
- **Процент силы тяги** от максимума `|Freal|` в файле.
- **Сила сопротивления движению** по эмпирической формуле:
  ```
  F = (5.2 + (34.2 + 0.732·V + 0.022·V²) / B10) · B6 · N1
  ```
  где `V` — сглаженная скорость, `B10` — средняя осевая нагрузка, `B6` — масса поезда,
  `N1` — коэффициент сопротивления.
- **Ускорение от силы сопротивления** (всегда тормозящее, знак «−»).
- **Сумма ускорений** — простая сумма всех вкладов (знак уже заложен в каждом компоненте).
- **Дребезг ускорения** — локальный размах `max − min` в окне ±Δt секунд.
- **Коэффициент K** = сглаженное ускорение / сумма ускорений, с фильтрацией по дребезгу
  и фильтром Калмана с «заморозкой» (последнее валидное значение держится на шумных участках).
- **Ускорение с учётом K** = сглаженное ускорение × K.

### Визуализация
- **Два графика** (верхний/нижний), каждая — с произвольным набором колонок.
- **Сохранение зума** при смене столбцов («Применить», «Сбросить») — вид восстанавливается.
- **Сброс зума** по кнопке «⤢ Вид» или при новом расчёте.
- **Специальные стили отрисовки**:
  - коридоры `default`-сглаживания — `fill_between` + пунктирные границы;
  - «Тяга» и «Тормоз» — гистограмма (`bar`);
  - «ТЦ» — порог зануления;
  - «Сумма ускорений», «Коэффициент K», «Ускорение с учётом K» — толще и поверх остальных.

### Интерактивность
- **Вертикальная линия-курсор** при наведении на любой график (в обеих осях одновременно).
- **Панель «Значения в точке»** — все числовые колонки в позиции курсора.
- **Режим выделения** (drag) — прямоугольник на обоих графиках и автоматический
  расчёт статистики (среднее, мин, макс, ст.откл) по всем колонкам.
- **Выделить всю область** — на весь временной диапазон.
- **Экспорт выделенного интервала в Excel**.
- **Сворачиваемая панель управления** — кнопка `◀`/`▶` или горячая клавиша **F9**.

### UI/UX
- Светлая тема оформления (`clam`): белые карточки, мягкий серо-голубой фон,
  акцентный синий цвет, зелёный/оранжевый/красный для кнопок действий.
- **Всплывающие подсказки** для всех настраиваемых параметров.
- Единый стиль кнопок (крупные и компактные варианты).
- Автоподбор `y`-диапазона с защитой от выбросов (NaN-разрывы в графике).

## Установка и запуск

### 1. Клонировать репозиторий
```bash
git clone https://github.com/ваш-логин/train-speed-analyzer.git
cd train-speed-analyzer
```

### 2. Установить зависимости
```bash
pip install -r requirements.txt
```

### 3. Запустить приложение
```bash
python main.py
```

## Быстрый старт

1. **Выбрать Excel-файл** — приложение определит колонки времени и скорости,
   подтянет `Freal` (сила тяги).
2. Настроить параметры сглаживания (или оставить значения по умолчанию).
3. Нажать **Выполнить расчёт** — построятся графики скорости и ускорения.
4. В панели справа:
   - кнопкой **«Выбрать…»** задать столбцы для верхнего и нижнего графиков;
   - **«✓ Применить»** — перерисовать графики, сохранив зум;
   - **«↺ Сбросить»** — вернуть столбцы по умолчанию;
   - **«⤢ Вид»** — сбросить зум к авто-масштабу;
   - включить **«Режим выделения»** и протянуть мышью по графику для статистики;
   - **«В Excel»** — сохранить выделенную область.
5. Свернуть панель — кнопка **`▶`** в шапке или **F9**.

## Формулы

Все расчёты выполняются в `gui.py` в методе `SpeedAnalyzerApp.calculate()`.

### Константы

| Константа | Значение | Единица | Комментарий |
|---|---|---|---|
| `TRAIN_MASS_T` | 7337 | т | масса поезда |
| `INERTIAL_MASS_K` | 0.07 | — | коэффициент инерционной массы |
| `INERTIAL_MASS_T` | `TRAIN_MASS_T · 0.07` = 513.59 | т | инерционная добавка |
| `TOTAL_MASS_KG` | `(TRAIN_MASS_T + INERTIAL_MASS_T) · 1000` = 7 850 590 | кг | полная масса |
| `AXLE_LOAD_T` (B10) | 24.78716216 | т | средняя осевая нагрузка |
| `RESISTANCE_COEF` (N1) | 1.25 | — | коэффициент сопротивления |
| `FREAL_TO_N` | 1000 | кН → Н | перевод силы тяги |

### Расчётные величины

| № | Величина | Формула | Единица |
|---|---|---|---|
| 1 | Сила тяги | `Freal_кН · 1000` | Н |
| 2 | Сглаженная скорость | `smooth_default(V_км/ч)` (любой из 5 алгоритмов) | км/ч |
| 3 | Скорость в м/с | `V_used / 3.6` | м/с |
| 4 | Ускорение (сырое) | `(V_ms[i] − V_ms[i−10]) / (t[i] − t[i−10])` | м/с² |
| 5 | Сила от уклона | `Уклон · TRAIN_MASS_T · 9.81` | Н |
| 6 | Ускорение от уклона | `−F_уклона / TOTAL_MASS_KG` | м/с² |
| 7 | Ускорение от силы тяги | `Freal_Н / TOTAL_MASS_KG` | м/с² |
| 8 | Сила сопротивления движению | `(5.2 + (34.2 + 0.732·V + 0.022·V²) / B10) · B6 · N1` | Н |
| 9 | Ускорение от силы сопротивления | `−F_сопр / TOTAL_MASS_KG` | м/с² |
| 10 | Сумма ускорений | `a_тяги + a_уклона + a_сопр` | м/с² |
| 11 | Процент силы тяги | `\|Freal\| / max(\|Freal\|) · 100` | % |
| 12 | Дребезг ускорения | `max(a) − min(a)` в окне `[t−Δt, t+Δt]` | м/с² |
| 13 | Коэффициент K | `a_сглаж / a_сумм` при `дребезг < порога` | — |
| 14 | Ускорение с учётом K | `a_сглаж · K` | м/с² |

где:

- `V` — **сглаженная** скорость в км/ч (колонка `Сглаженная скорость`, либо сырая, если сглаживание выключено);
- `B6` = `TRAIN_MASS_T` = масса поезда, т;
- `B10` = `AXLE_LOAD_T` = средняя осевая нагрузка, т;
- `N1` = `RESISTANCE_COEF` = коэффициент сопротивления движения (вкладка «Режим»).

### Знаковая конвенция

**Разгоняющие силы → «+», тормозящие → «−».**

| Компонент | Знак |
|---|---|
| Ускорение от силы тяги | `+` при тяге (`Freal > 0`), `−` при эл. тормозе (`Freal < 0`) |
| Ускорение от уклона | `−` при подъёме (`Уклон > 0`), `+` при спуске (`Уклон < 0`) |
| Ускорение от силы сопротивления | всегда `−` |
| Сумма ускорений | знак уже заложен в каждом компоненте, поэтому формула — простое сложение |

**Смысл знака суммы:**
- `a_сумм > 0` → поезд **разгоняется**;
- `a_сумм < 0` → поезд **тормозит**.
